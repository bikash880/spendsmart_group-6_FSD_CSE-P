# Currency Converter

A **real-time currency conversion application** developed using Python and Tkinter. This application enables users to convert amounts between different currencies using **live exchange rates** retrieved from an online API. It provides a simple, attractive, and easy-to-use graphical interface.

## 🚀 Features

✅ **Live Exchange Rates** fetched automatically from an online API  
✅ Supports **50+ global currencies** for flexible conversion  
✅ **Simple and interactive Tkinter interface** with currency dropdown menus  
✅ **Dark-themed interface** for a clean and comfortable viewing experience  
✅ **Quick Currency Conversion** with a single click  
✅ **Input validation** to ensure that only valid numeric amounts are entered  
✅ **Currency Swap Option** to easily exchange the From and To currencies  
✅ **Error Handling** for invalid inputs and API/network issues  
✅ **Background Threading** to keep the application responsive while fetching rates  

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Tkinter** – Used to create the graphical user interface
- **Tkinter.ttk** – Provides enhanced and styled UI components
- **Requests** – Used for connecting to the currency exchange API
- **Threading** – Prevents the application interface from freezing during API requests
- **Exchange Rate API** – Provides current currency conversion rates
